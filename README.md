# AluraPlay

A YouTube homepage clone, built with pure HTML and CSS: header with search bar, sidebar navigation, topic filter bar and a video grid with embedded YouTube players.

Built while practicing flexbox layouts at Alura.

## Stack

- HTML5
- CSS3 - flexbox, split into `reset.css`, `estilos.css` and `flexbox.css`
- Google Fonts (Roboto)
- YouTube iframe embeds for the video thumbnails/players

## Running locally

No build step - open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then go to http://localhost:8000.
